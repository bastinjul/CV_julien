Master's thesis

This video shows a demonstration of a real-time person tracking device using sonars. This work was done with Guillaume Neirinckx for our master's thesis, supervised by Peter Van Roy and Igor Kopestenski at UCLouvain during the 2019-2020 academic year. It was presented in a talk given by Peter Van Roy on August 23, 2020 at the Erlang Workshop 2020 (co-located with ICFP 2020). The talk slides are available here and our master's thesis is available below.

GitHub repositories:

  • Hera framework: Erlang framework that synchronizes and filters sensor data between Erlang nodes.
  • Sensor fusion on GRiSP: application running on the GRiSP board. It uses the Hera framework and can track up to two people in a room using sonars.
  • Sensor fusion live view: Elixir Phoenix LiveView application displaying the tracked people in the room.
  • Hera synchronization library: Erlang library used by the Hera framework to synchronize sensor measurements and prevent crosstalk between sonars.
